# 🌿 Fieldnote – Student Placement Tracker

**A Smarter Way to Track Student Placement Readiness**

Fieldnote is a responsive student placement tracking dashboard designed to help placement coordinators manage student records, monitor placement readiness, and visualize cohort progress through a clean and interactive interface.

## 🚀 Project Overview

Managing student placement data can become difficult when records, interview readiness, and placement updates are maintained manually.

Fieldnote provides a centralized dashboard where coordinators can organize student information, track their placement status, and monitor overall cohort performance.

## ✨ Key Features

- **Dashboard Overview:** View total students, interview-ready students, successfully placed students, and placement rate.
- **Student Management:** Add, edit, and delete student records.
- **Placement Tracking:** Categorize students into Learning, Interview Ready, and Placed.
- **Search Functionality:** Quickly find students using the search bar.
- **Status Filters:** Filter student records according to placement status.
- **Interactive Analytics:** Visualize placement progress across different learning domains.
- **CSV Export:** Download student records for further analysis.
- **Responsive Design:** Access the dashboard across desktop, tablet, and mobile screens.
- **Local Storage:** Save student records in the browser.

## 💻 Getting Started

Follow these steps to run Fieldnote locally.

**1. Clone the repository**

```bash
git clone https://github.com/joshiriya-282/spsu-placement-tracker.git
```

**2. Navigate to the project folder**

```bash
cd spsu-placement-tracker
```

**3. Run the project**

Open `index.html` in your web browser.

You can also use the Live Server extension in VS Code.
